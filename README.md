> **Objects made to be kept.**

A fully responsive, animation-rich ecommerce storefront built with pure HTML, CSS, and JavaScript — no frameworks, no build tools, no dependencies.

## ✨ Overview

ATELIER is a design-forward ecommerce experience crafted to feel like a real premium storefront. From an immersive cinematic slideshow to a fully functional cart, wishlist, and multi-step checkout — everything runs in a single HTML file.

Built with an editorial aesthetic, tactile micro-interactions, and a mobile-first responsive layout.

## 🎯 Features

### Storefront Experience
- **Login / Signup Gate** — Full-screen entry with tabs, social login, guest checkout
- **Cinematic Hero Slideshow** — 5 slides with curtain-wipe transitions, Ken Burns zoom, masked text reveals, vertical thumbnail rail, and rotating scroll badge
- **Auto-Scrolling Ribbon** — Dual-direction infinite product marquee (pauses on hover)
- **48 Products / 9 Categories** — Watches, Audio, Bags, Eyewear, Footwear, Apparel, Home, Accessories, Stationery
- **Category Filters** — Instant client-side filtering with smooth scroll
- **Editorial Sections** — Story-driven brand blocks with hover zoom collage
- **Newsletter Signup** — With toast confirmation

### Commerce Functionality
- **Full-Featured Search** — Full-screen overlay with live results, popular suggestions, inline add-to-cart & wishlist buttons
- **Wishlist System** — Persistent heart states, dedicated drawer, "Move to Cart" action, header badge count
- **Cart Drawer** — Quantity controls, live totals, free-shipping progress bar
- **3-Step Checkout** — Shipping → Payment → Confirmation
  - **Payment Methods:** Card, UPI, Net Banking, Cash on Delivery
  - **Live Validation** — Email, PIN code, card number, expiry, CVV, UPI ID
  - **COD Handling Fee** — Auto-applied ₹49
  - **Animated Success State** — Order ID generation with SVG checkmark draw

### Motion & Interaction
- Reveal-on-scroll animations
- Button shine sweeps and lift effects
- Cart badge pop animations
- Toast notifications for all actions
- Rotating circular scroll indicator
- Masked line-by-line headline reveals
- `prefers-reduced-motion` support

### Responsive Design
- **Desktop (≥ 861px)** — Full navigation, thumbnail rail, all hero controls
- **Mobile (≤ 860px)** — Hamburger menu with slide-in drawer, adaptive grid, touch-friendly actions
- **Extra-small (≤ 560px)** — Single-column layouts, full-width drawers, stacked forms
